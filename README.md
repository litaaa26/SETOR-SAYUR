Setor Sayur adalah aplikasi web interaktif yang dikembangkan menggunakan HTML, Tailwind CSS, dan JavaScript. Fitur utama meliputi:

Halaman Login Aman: Sistem autentikasi pengguna.

Dashboard IoT Composting Box: Memantau kapasitas, suhu, dan kelembapan tiga kategori box (Hijau, Kuning, Merah).

Interactive Sorter: Alat bantu pencarian otomatis untuk memilah jenis sampah organik dengan tepat.

Gamifikasi & Tukar Poin: Mengubah sampah menjadi poin yang dapat ditukar dengan voucher, e-wallet, atau pupuk organik.

Jadwal Penjemputan & Kalkulator Karbon: Fitur logistik penjemputan sampah dan pelacakan dampak pengurangan emisi CO2e.
